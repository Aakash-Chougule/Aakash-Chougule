👨‍💻 About Me

I am a .NET-focused software developer who enjoys building practical, maintainable applications that solve real business problems.

My strongest focus is on C#, ASP.NET Core, REST APIs, Entity Framework Core, relational databases, authentication/authorization, and backend architecture. I also work across the frontend with React, JavaScript, HTML, CSS, Bootstrap, Tailwind CSS, and Vue.js.

I like projects where I can understand the complete flow — database → backend → API → authentication → business logic → frontend → testing → deployment — instead of treating each part as an isolated task.

🔭 Currently building an Enterprise E-Commerce & Order Management System

🧠 Strengthening system design, clean architecture, event-driven messaging, Docker, cloud, and CI/CD

🔐 Interested in secure APIs, JWT authentication, role-based authorization, and clean backend design

🧩 Comfortable working with business rules, CRUD workflows, SQL, API integration, debugging, and maintenance

🎯 Open to opportunities in .NET / Backend / Full-Stack Development

📍 Based in India

My goal: build software that is not only functional, but understandable, testable, secure, and maintainable.
